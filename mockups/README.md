# Mockups

Static, throwaway UI mockups used to make design decisions before the real
Next.js build. Not production code — the *decisions* carry forward, the HTML
does not.

## `void-mockup.html`

A single self-contained file (inline CSS/JS, sample data). Open it directly in
a browser:

```
open mockups/void-mockup.html      # macOS
```

Covers Dashboard, Members, Strongholds, Events (placeholder), Trends, and
Admin. Nav, member search/filter, and the live server/local clocks are
interactive. Responsive down to mobile.

Design direction: dark "survival HUD" — cosmic-void violet as the primary
accent, desert amber reserved for sanctum buffs, semantic green/amber/red for
status; monospace for the wordmark, data, and labels.
